# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子，**必须点选温带（高温带 / 低温带），漏点整笔退回**。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。

## 温带与判定

- 高温带、低温带各守一套填充因子闭区间 `[下限, 上限]`，全场不共用一条线。
- 初始值：低温带 `[0.65, 0.72]`，高温带 `[0.72, 0.85]`；落在闭区间内判 **合格**，区间外判 **衰减**。
- 判定只吃现行闭区间；工人认领那一瞬把上下限抄进**认领抄本**，已领走的单继续用抄本里的上下限。
- 顶栏「温度补偿」专页三格：上格温带、中格改带履历、下格认领抄本。没设过温带时显示「还没设温带」。
- 观察员（watcher）只能翻温带和履历，不许改带也不许入队。

页面是 Vue 3。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/logs | 扫描单列表（含温带） |
| POST | /api/logs | 录单，`band` 必填，漏带整笔退 |
| GET | /api/bands | 现行温带闭区间 |
| POST | /api/bands | 改带（仅扫描员），自动写履历 |
| GET | /api/bands/history | 改带履历 |
| GET | /api/claim-ledger | 认领抄本 |
